A [make.fun](https://make.fun) entry for **Five Seconds to Explain the Glass**: the one sentence a house cat would say in its own defence in the five seconds after sweeping a glass off the table. No apology, no confession — just the most convincing excuse a cat can make for itself.

## The sentence

> That glass was squatting dead center in my sunbeam, so really I just evicted a trespasser with excellent paw technique.

(119 characters, one sentence.)

## Run

```sh
python3 main.py
```

This deterministically writes the sentence to `/output/entry.txt`, byte-identical on every run.
